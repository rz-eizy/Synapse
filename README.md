# Planteamiento del Proyecto:
Red para Tutores/Cuidadores de Niños Neurodivergentes

# Nombre de app:
Synapse

# Justificacion de Seleccion:
Se consideró que la red para tutores era la opción más óptima, ya que es un problema cuya solución es carente de competencia y proveerá de una ayuda significativa a los cuidadores que sufren de enorme carga mental y emocional por la naturaleza de sus funciones, de igual manera presentará un apoyo significativo a generar un espacio seguro donde personas que son neurodivergentes podrán aprender de manera clara sus ideas.
